# Сергей Рассолов

**Software Engineer / Backend-разработка и внутренние инструменты бизнеса**

Основное направление: C# / .NET. Создаю API, веб-приложения и инструменты, которые помогают организовать рабочий процесс, связать данные из разных систем и сократить ручные операции.

Развиваю собственную студию цифровых 3D-продуктов. Этот опыт помогает видеть задачу с двух сторон: как разработчику и как владельцу процесса. Разбираюсь, почему возникают переделки, где теряется контекст и какие решения стоит принимать раньше. Перевожу эти проблемы в требования, модели данных и рабочие инструменты.

Использую AI там, где он помогает искать контекст, готовить варианты и ускорять реализацию. Проверки целостности, ограничения доступа и критерии готовности задаю явно; результат проверяю кодом, тестами и рабочими сценариями.

## Инженерные кейсы

Внутренние инструменты, созданные для реальных задач бизнеса. Публичные описания показывают исходную проблему, причины выбранного решения, архитектуру и ограничения. Рабочие исходники и коммерческие данные закрыты. Оба кейса доступны на русском и английском.

### [3D Production Workbench](https://github.com/RassolovSergey/3d-production-workbench)

**Организация производства 3D-коллекции от идеи до подготовленной модели.**

Проблема: производство отдельных моделей начиналось до согласования полного набора; референсы находились на разных стадиях готовности, а поздние решения приводили к переделкам. В кейсе описаны разделение этапов, ревизии, подготовка партий, происхождение файлов и контроль импорта.

Node.js · TypeScript · SQLite · Python · Blender tooling · MCP · LangGraph

### [Marketing System](https://github.com/RassolovSergey/marketing-system-showcase)

**Маркетинговые данные, история кампаний и переписки в одном рабочем пространстве.**

Проблема: показатели распределены по сервисам, а доступ к сообщениям зависел от задержек внешнего API. Решение объединяет сохранённые данные, фоновое обновление и явные состояния свежести, ошибок и ограничений провайдера.

React · Node.js · PostgreSQL · Docker Compose · REST/GraphQL · Webhooks
